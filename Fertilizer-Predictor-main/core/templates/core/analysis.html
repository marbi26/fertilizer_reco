Dataset Information

The model utilizes 8 distinct physical inputs to predict the target chemical fertilizer class.

Feature Name Type Unit / Range Description
Nitrogen (N) Numerical 0 - 150 mg/kg Primary nutrient key to chlorophyll production and foliage growth.
Phosphorus (P) Numerical 0 - 150 mg/kg Primary nutrient vital for root structure development, flowering, and seeding.
Potassium (K) Numerical 0 - 150 mg/kg Primary nutrient key for enzyme activation, water absorption, and disease resistance.
Temperature Numerical 10°C - 50°C Ambient field temperature affecting plant metabolic activity.
Humidity Numerical 10% - 100% Atmospheric humidity level influencing transpiration rates.
Moisture Numerical 10% - 100% Soil water retention ratio measuring moisture density.
Soil Type Categorical 5 classes Sandy, Loamy, Black, Red, or Clayey soil classification.
Crop Type Categorical 11 classes The plant species currently sown in the field (e.g. Paddy, Wheat, Cotton).
Recommended Fertilizer Target 7 classes The optimal output fertilizer (Urea, DAP, MOP, or custom NPK blend).
